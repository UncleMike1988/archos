## How to use this file

This file maps bellwether-named AI-infrastructure chokepoints to sub-$5B pure-plays. When a bellwether (NVDA / TSMC / AVGO / Microsoft / Meta / AMD) mentions a chokepoint in earnings or at an industry event, scan the Active Taxonomy for candidate companies on that chokepoint. When screening a new candidate, the candidate's chokepoint must appear in this table — if it doesn't, either the chokepoint belongs to the Monitor list, the Rejected list, or the taxonomy is stale and needs a refresh.

H10 tier matters for conviction:
- **Vendor-level** = bellwether named the specific company or made a direct equity investment. Strongest signal.
- **Category-level** = bellwether named the chokepoint category but not a specific vendor. Requires H8 + H5 + H11 to do more screening work.

**Status column** (added 2026-05-27 after real-time price audit):
- **ACTIVE** — Current market cap < $5B; framework H8 filter applies; in entry window.
- **EMPTY** — Chokepoint is bellwether-validated but every prior sub-$5B pure-play has graduated. Needs fresh discovery search.
- **MONITORING** — Data incomplete or status changing rapidly; verify before any new DD.

**H8 Tier column** (added 2026-05-27 Framework v2.0):
- **TIER 1 NANO** — sub-$500M (highest asymmetry 16-100x; equity only)
- **TIER 2 CATALYST** — $500M-$2B (strong asymmetry 5-20x; LEAPS preferred)
- **TIER 3 COMPOUNDER** — $2B-$5B (moderate asymmetry 3-10x; LEAPS preferred)
- **GRADUATED** — Above $5B (entry window closed for this entity)
