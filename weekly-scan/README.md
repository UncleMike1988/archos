# Weekly run system

Run these every week (Sunday works well). Each is self-contained — paste it into a fresh Code session.
Order doesn't strictly matter, but this sequence flows well:

1. **WATCHLIST_RECHECK.md** — start by rechecking what you already track. What fired, what broke, what's
   window-closing. (Status check, not a hunt.)
2. **BUCKET2_CATALYST_HUNT.md** — the bellwether-constraint + supply-chain hunt for $1-5B catalyst growers.
   (The workhorse — most weeks this is where the action is.)
3. **BUCKET1_MOONSHOT_HUNT.md** — the wide net for sub-$1B ignored moonshots with a fresh catalyst.
4. **BUCKET3_DERATED_HUNT.md** — quality names de-rated on fear that didn't materialize; the LEAPS bucket.

Each writes a dated file to `runs/`. Hunts append new names to `../WATCHLIST.md`; the recheck updates it.
All four follow the charter: bird-dog first, verify second; no invented scores/tiers/frameworks; leads,
not buy calls; the operator decides everything.

`runs/` keeps the history so you can see how a name's story evolves week over week. Old-system prompts are
parked in `_archive_old_prompts/` — do not run them.
