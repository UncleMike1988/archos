## Tool-stack lessons (Screen 9 first run)

- **EdgarTools `search_filings_full_text` + items=['5.02']** is the canonical primary-source query for board appointment discovery. High-precision when paired with rank/agency phrase queries.
- **Single-phrase queries only** (per persistent INSIGHTS.md note). Multi-condition AND queries return zero hits. "Lieutenant General", "Major General", "Rear Admiral", "Vice Admiral", "Brigadier General", "four-star" each query individually.
- **Item 5.02 + military rank phrase + 12-month window** produced ~30 candidate appointments. Triage by (a) sub-$1B cap, (b) defense-relevant company, (c) external Board/Advisory Board (not internal promotion) = 4 sub-$1B hits worth deep review.
- **WebFetch is blocked by SEC EDGAR (HTTP 403).** Use WebSearch for press release content + StockTitan / GlobeNewswire / SEC company-IR pages as alternate primary sources.
- **Mega-cap noise filter:** SAIC / NOC / CACI / TPG / RPM / IONQ / TTMI / C3.ai are the standard "senior officer board appointments" sinks. All correctly excluded by sub-$1B cap filter.
- **Cluster 8 SPAC noise filter:** CAII / GIW / HLEO surface multiple senior officers on a SPAC IPO entity. Correctly routed to REJECT.
- **Inverse signal query "resigned" + Item 5.02** returns 64KB of results (too large). Web search refinement of "resigned from the board defense company" is more efficient for inverse-signal discovery.
