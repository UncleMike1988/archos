- **"NVIDIA Cloud Partner" certification** as a pre-screening signal (SHAZ case) — direct NVDA-issued accreditation that captures vendor-level chokepoint #7 conviction without requiring a verbatim earnings-call quote. May want to add NCP certification as an explicit H10 vendor-level trigger.

### Tool-stack issues encountered

1. **EdgarTools 8-K full-text search is the workhorse — query design matters.** "Design win" + AI returned a usable set of 5 hits; "capacity expansion" + data center returned 24 hits; "record backlog" returned 68 hits (too noisy with non-AI industrials). The most productive queries were narrow phrase combinations, not single keywords. Plan to use a tighter "AI-data-center capacity expansion" / "AI-DC long-term agreement" / "B300 GPU" / "neocloud" composite query set for the weekly cadence run.
2. **EdgarTools market caps unreliable — confirmed AGAIN.** AAOI revenue commentary referenced in EdgarTools showed correct dollar amounts but XBRL-derived market caps were absent. All market caps in this screen sourced from web search (stockanalysis.com / Robinhood / Investing.com / company IR) per INSIGHTS.md mandate.
3. **Aschenbrenner 13F is the highest-yield single source** — confirmed Phase 3 lesson. SHAZ, TE both surfaced cleanly from this. 13f.info SUMMARY page does not return full holdings; needed trendspider article + dave manuel + multiple cross-checks to assemble the equity-long-position list.
4. **Foreign filer 13F surfacing is weak.** SIVEF (Swedish primary listing) is not in the US 13F system in any meaningful way. Specialists who hold the Swedish primary do not show up in US 13F-HR. This is a known limitation — the framework's H7 was already downgraded in Phase 3 for this reason among others.
5. **LunarCrush coverage on sub-$1B float names is thin** — true again. SHAZ, SIVEF, DUOT all had insufficient LunarCrush coverage to drive H5 quantitatively; FinTwit/Reddit volume estimates came from manual narrative scan.
6. **Bitcoin-miner sector pivot is now industrialized.** Aschenbrenner doubled down on BITF, CLSK, RIOT (already-known APLD-class pivots) and ADDED HIVE as a NEW. The framework explicitly screens these out as out-of-scope blind-spot — confirmed working as intended.
7. **NN Inc (NNBR) is the cleanest BW-blind-spot test case so far.** Sub-$150M mkt cap, IGNORED, grid + data center 8-K language, but AI-infra revenue still ~20% with auto dominant. The framework correctly screens it out. **This is real-time confirmation that the H8 end-market filter holds against legacy-industrial capacity pivots when the pivot is partial.**
